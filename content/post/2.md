## 概述

[LE-Monitor](https://github.com/lework/lemonitor)（lemonitor） 是一个开源项目，由 Lework 发起并维护，主要功能是收集并展示开源软件在中国境内的官方镜像站点，本文将讲解如何在docker启用该项目

## docker run

单条命令

```bash
docker run -d \
  --name lemonitor \
  --restart always \
  -p 6780:80 \
  swr.cn-north-4.myhuaweicloud.com/jeven/lemonitor:latest
```

## docker-compose

创建/data/lemonitor目录，并进入到/data/lemonitor目录
```bash
mkdir -p /data/lemonitor && cd /data/lemonitor/
```
创建docker-compose.yaml并编辑
我个人喜欢用nano直接编辑
```bash
nano docker-compose.yaml
```

### docker-compose.yaml内容
```
services:
  lemonitor:
    image: swr.cn-north-4.myhuaweicloud.com/jeven/lemonitor:latest
    container_name: lemonitor
    restart: always
    ports:
      - 6780:80

```
CTRL+X，并输入Y保存退出，</br>
在当前目录下执行docker-compose up -d (或docker compose up -d)</br>

看到命令行出现下面内容，就表示该项目正常运行。
```
[+] Running 1/1
 ✔ Container lemonitor  Running  
```
接下来打开浏览器，输入ip:端口</br>
比如我在192.168.1.229设备上装的该项目，</br>
就输入http://192.168.1.229:6780</br>
